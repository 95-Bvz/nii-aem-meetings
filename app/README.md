# Информационная система планирования совещаний НИИ АЭМ

Веб-приложение для планирования и учёта внутренних совещаний и мероприятий Научно-исследовательского института атомного энергетического машиностроения.

## Функциональные возможности

### Управление совещаниями
- Создание, редактирование и удаление совещаний
- Планирование даты, времени и места проведения
- Назначение организатора и участников
- Категоризация по типам (планёрка, техсовет, научный совет и т.д.)
- Отслеживание статуса (запланировано, проводится, завершено, отменено)

### Протоколирование
- Создание протоколов совещаний
- Фиксация принятых решений
- Создание задач и поручений с назначением ответственных и сроков
- Отслеживание выполнения задач

### Управление ресурсами
- Каталог переговорных комнат с характеристиками (вместимость, оборудование)
- Проверка доступности комнат на выбранное время
- Расписание комнат по неделям

### Управление персоналом
- Каталог сотрудников с должностями и контактами
- Организационная структура (подразделения)
- Статистика участия в совещаниях

### Календарь и отчётность
- Интерактивный календарь с фильтрацией по комнатам
- Отчёты по совещаниям за период
- Анализ загрузки переговорных комнат
- Статистика активности сотрудников
- Отчёт по задачам и поручениям

## Технологии

- **Backend:** Python 3.11+, Flask 3.0
- **База данных:** SQLite (SQLAlchemy ORM)
- **Frontend:** HTML5, CSS3, JavaScript
- **UI Framework:** Bootstrap 5.3
- **Календарь:** FullCalendar 6
- **Графики:** Chart.js

## Установка и запуск

### 1. Клонирование и настройка окружения

```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux/Mac)
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Инициализация базы данных

```bash
python init_db.py
```

Скрипт создаст базу данных с тестовыми данными:
- Пользователи (admin, manager, user)
- Подразделения НИИ
- Сотрудники
- Переговорные комнаты
- Типы совещаний
- Примеры совещаний с протоколами

### 3. Запуск приложения

```bash
python run.py
```

Приложение будет доступно по адресу: http://localhost:5000

### Учётные записи

| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | admin | admin123 |
| Менеджер | manager | manager123 |
| Пользователь | user | user123 |

## Модели данных

### User (Пользователь)
- Аутентификация и авторизация
- Роли: admin, manager, user

### Department (Подразделение)
- Организационная структура НИИ

### Employee (Сотрудник)
- ФИО, должность, контакты
- Привязка к подразделению

### Room (Переговорная комната)
- Расположение, вместимость
- Оборудование (проектор, ВКС, доска)

### MeetingType (Тип совещания)
- Категории с цветовой маркировкой

### Meeting (Совещание)
- Дата, время, место
- Организатор и участники
- Статус жизненного цикла

### Protocol (Протокол)
- Содержание и решения
- Номер протокола

### Task (Задача)
- Поручения из протоколов
- Ответственный и срок
